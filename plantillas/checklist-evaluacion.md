# Checklist de Evaluacion del Hackathon

## 1) Entendimiento del problema
- [ ] Problema de negocio claramente definido
- [ ] Metrica objetivo declarada
- [ ] Alcance realista para un piloto

## 2) Calidad del agente
- [ ] Respuestas claras para usuario no tecnico
- [ ] Tono consistente y profesional
- [ ] Manejo correcto de casos ambiguos

## 3) Seguridad y cumplimiento
- [ ] No expone datos sensibles
- [ ] Declara limites de lo que puede hacer
- [ ] Escala a humano en casos criticos

## 4) Experiencia conversacional
- [ ] Flujo natural de preguntas y respuestas
- [ ] Evita repetir datos ya compartidos
- [ ] Buen cierre con proximo paso accionable

## 5) Valor de negocio
- [ ] Beneficio esperado cuantificado
- [ ] Riesgos identificados
- [ ] Plan de adopcion inicial definido
