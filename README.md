# Copilot Studio Banking Hackathon

Repositorio de retos para un hackathon orientado a la industria bancaria.

## Proposito
Este material ayuda a equipos no tecnicos a entender conceptos basicos de AI agentica con Microsoft Copilot Studio, construyendo agentes paso a paso.

## Estructura
- `doc.md`: Caso de uso, alcance, objetivo del evento y ruta de adopcion.
- `retos/`: 5 retos progresivos.
- `plantillas/`: formatos para documentar agentes y evaluar entregables.
- `materiales/`: datos y prompts base para acelerar la practica.

## Ruta sugerida
1. Leer `doc.md`.
2. Ejecutar retos en orden (`reto-01` a `reto-05`).
3. Usar `plantillas/template-ficha-agente.md` para cada agente.
4. Evaluar con `plantillas/checklist-evaluacion.md`.

## Resultado esperado
Al finalizar, cada equipo debe tener:
- 3 agentes funcionales en Copilot Studio.
- 1 flujo de handoff entre agentes.
- 1 propuesta de adopcion para su area de negocio.
