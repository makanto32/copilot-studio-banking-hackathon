# Reto 05 - Agente orquestador de experiencia

## Objetivo
Conectar varios agentes especializados bajo una experiencia unica de cliente.

## Actividades
1. Definir reglas de enrutamiento entre agentes.
2. Configurar contexto compartido minimo.
3. Probar transiciones FAQ -> onboarding -> fraude.
4. Medir coherencia y continuidad de la experiencia.

## Entregables
- Flujo orquestado entre agentes.
- Diagrama simple de handoffs.
- Demo final de punta a punta.

## Criterio de exito
El cliente no repite informacion y percibe continuidad en la conversacion.
