# Reto 04 - Agente de alertas de fraude

## Objetivo
Diseñar un agente que explique alertas preventivas y recomiende acciones de contencion para el cliente.

## Actividades
1. Definir eventos de alerta tipo (consumo inusual, geografia atipica, multiples intentos).
2. Crear mensajes claros y no alarmistas.
3. Definir protocolo de verificacion de identidad.
4. Simular 5 conversaciones de alto riesgo.

## Entregables
- Agente de alertas con respuestas guiadas.
- Reglas de handoff a equipo de fraude.
- Matriz de casos de prueba.

## Criterio de exito
Mensajes comprensibles, accionables y alineados a buenas practicas de riesgo.
