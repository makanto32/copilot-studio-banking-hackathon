# Reto 03 - Agente de onboarding de cuenta

## Objetivo
Crear un agente que guie a un cliente nuevo en pasos de apertura de cuenta de manera clara y ordenada.

## Actividades
1. Diseñar flujo conversacional de onboarding.
2. Incluir preguntas de elegibilidad basica.
3. Agregar validaciones de datos minimos.
4. Configurar handoff a humano para excepciones.

## Entregables
- Flujo de onboarding en Copilot Studio.
- Politica de escalamiento a asesor humano.
- Script de prueba con 5 escenarios.

## Criterio de exito
Reducir friccion conversacional y evitar mensajes ambiguos.
