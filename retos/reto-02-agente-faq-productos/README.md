# Reto 02 - Agente FAQ de productos bancarios

## Objetivo
Construir un agente en Copilot Studio que responda preguntas frecuentes sobre productos bancarios.

## Actividades
1. Definir top 20 preguntas frecuentes.
2. Cargar base de conocimiento inicial.
3. Configurar tono, limites y mensajes de seguridad.
4. Probar al menos 10 conversaciones.

## Entregables
- Agente FAQ funcional.
- Evidencia de pruebas (capturas o log de prompts).
- Lista de mejoras detectadas.

## Criterio de exito
Al menos 80% de respuestas correctas en pruebas controladas.
